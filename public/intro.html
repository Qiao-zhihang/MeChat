Features

把聊天放进一个可探索的世界

MeChat 不只是聊天室，而是将即时通讯、用户身份、好友关系和空间位置组合成一个轻量但完整的开放世界应用。

01

开放世界移动

无限 2D 平面、WASD/方向键/虚拟摇杆移动，支持鼠标滚轮与双指缩放，点击坐标即可传送。

02

位置社交消息

世界留言基于坐标广播，消息历史会持久化保存，让附近的交流具备空间上下文。

03

好友与私信

支持好友申请、接受/拒绝、在线状态、一键传送至好友，以及好友间一对一私信。

04

用户身份系统

账号注册/登录、游客模式、自定义昵称、头像、主题色、个性签名，并通过会话持久化保持状态。

05

管理员治理

管理员可禁言、踢出、封禁、解封、全服广播、删除消息，并支持站长任命与撤销管理员。

06

移动端友好

虚拟摇杆、触摸手势、响应式布局与 PWA 支持，让手机也能进入这个实时聊天世界。

Architecture

实时、轻量、可扩展的技术栈

项目采用经典实时 Web 架构：Express 提供静态文件与 REST 认证，Socket.IO 承载核心实时业务，SQLite 负责持久化。

核心组件

  • Node.js / Express：HTTP 服务、静态文件、REST 路由。
  • Socket.IO：位置同步、消息收发、好友系统、私信与管理操作。
  • sql.js / SQLite：内存数据库运行，定时写入 data/mechat.db。
  • HTML5 Canvas：渲染开放世界、角色、消息气泡与网格视差。
  • PWA：manifest 与 Service Worker 支持离线缓存与安装体验。
Browser Canvas 渲染世界，Socket.IO 客户端发送移动、消息、社交事件。 →
Express + Socket.IO 服务器校验会话、权限、屏蔽关系与节流策略，并向在线用户广播。 →
SQLite 用户、好友、消息、封禁与禁言等数据写入内存库，并延迟持久化到磁盘。 →
Realtime UI 客户端接收实时事件，更新角色位置、消息列表、好友状态和管理反馈。 ↻

开始本地运行

Quick Start

几分钟启动本地服务

项目要求 Node.js 18 及以上。复制环境变量示例后，安装依赖并启动服务即可访问应用。

安装与启动

git clone https://github.com/Qiao-zhihang/MeChat.git
cd MeChat
cp .env.example .env
npm install
npm start

启动后访问 http://localhost:3000，介绍页可通过 http://localhost:3000/intro 打开。

环境变量

PORT=3000
ADMIN_KEY=your_admin_key
SUPER_ADMINS=your_username

ADMIN_KEY 用于管理员敏感操作，属于本地部署密钥，请不要提交到公开仓库。
